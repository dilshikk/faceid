# Пульт ботов

Админ-панель для нескольких ботов. Каждый бот подключается к своей базе PostgreSQL, а панель показывает пользователей, журнал событий и ошибки.

## Возможности
- Список ботов со статусом соединения и задержкой
- Подключение бота по адресу базы PostgreSQL (адрес хранится только на сервере)
- Выбор таблиц для разделов: пользователи, журнал, ошибки
- Просмотр данных с поиском и постраничной навигацией

## Стек
Vite, React, TypeScript, Tailwind CSS, Convex, Hercules Auth, pg

## Структура
- `convex/bots/` - серверная часть (схема подключений, работа с PostgreSQL)
- `src/pages/bots/` - страницы и компоненты панели
- `src/components/app-header.tsx` - шапка
