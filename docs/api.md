# REST API

Базовый путь: `/api/v1`. Все эндпоинты (кроме `/auth/login`) требуют
аутентификации через сессионную cookie (`SESSION_COOKIE_NAME`).
Мутации дополнительно ограничены rate-limit'ом (см.
`app/core/rate_limit.py`).

## Аутентификация — `auth.py`

| Метод | Путь | Описание | Роль |
|---|---|---|---|
| POST | `/auth/login` | Вход по имени пользователя и паролю, выдаёт сессионную cookie | — |
| POST | `/auth/logout` | Выход, отзывает текущую сессию | любой авторизованный |
| GET | `/auth/me` | Данные текущего пользователя (имя, роль) | любой авторизованный |

## Дэшборд — `dashboard.py`

| Метод | Путь | Описание |
|---|---|---|
| GET | `/dashboard/summary` | Сводка: сервисы по статусам, метрики сервера, здоровье PostgreSQL/Telegram, последние инциденты |

## Сервисы — `services.py`

| Метод | Путь | Описание | Роль |
|---|---|---|---|
| GET | `/services` | Страница сервисов (курсорная пагинация) | любой авторизованный |
| POST | `/services` | Зарегистрировать новый сервис (имя + systemd unit) | owner/admin |
| GET | `/services/{id}` | Детали одного сервиса и его текущий статус | любой авторизованный |
| PATCH | `/services/{id}` | Изменить имя, включённость, интервал опроса | owner/admin |
| GET | `/services/{id}/history` | История статусов | любой авторизованный |
| GET | `/services/{id}/logs` | Последние строки из journald (только для allowlisted unit) | любой авторизованный |

## Инциденты — `incidents.py`

| Метод | Путь | Описание | Роль |
|---|---|---|---|
| GET | `/incidents` | Страница инцидентов, фильтр по `status` | любой авторизованный |
| POST | `/incidents/{id}/acknowledge` | Подтвердить инцидент | owner/admin |

## Метрики — `metrics.py`

| Метод | Путь | Описание |
|---|---|---|
| GET | `/metrics/server` | Текущие CPU/RAM/диск/uptime сервера |

## Уведомления — `notifications.py`

| Метод | Путь | Описание | Роль |
|---|---|---|---|
| GET | `/notifications/settings` | Список настроек уведомлений (канал, тип события, cooldown, тишина) | любой авторизованный |
| PATCH | `/notifications/settings/{id}` | Изменить cooldown, включённость или поставить на паузу (`silence_minutes`) | owner/admin |

## Коды ошибок

Все ошибки возвращаются как `HTTPException` со стандартным телом
FastAPI (`{"detail": "..."}`) и соответствующим HTTP-статусом:
`400` — неверный запрос, `401` — не авторизован, `403` — нет прав,
`404` — не найдено, `409` — конфликт (например, сервис уже
зарегистрирован), `429` — слишком много запросов.
